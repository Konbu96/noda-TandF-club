## 決定サマリー

| 領域 | 決定内容 |
|------|---------|
| ログイン | メール/パスワード **と** Google ログインの両方 |
| **利用者** | **部内全員**（先生・マネージャー・キャプテン・ブロック長・部員） |
| 部員アカウント | **`/login` から自己登録**。名簿メール一致で自動紐づけ（**招待リンクなし**） |
| 休み・欠席 | **アプリでは管理しない**（LINE 等で連絡） |
| キャプテン | **1人**。全部員を**閲覧**可。PB・メニューは**全員分**編集可 |
| ブロック長 | キャプテンとは別枠。担当ブロックの**メニュー作成のみ**（委任想定） |
| PB 入力 | **部員が自分で入力可**。管理者も入力可 |
| PB 削除 | **管理者のみ**（部員は編集可・削除不可） |
| 体調の公開 | デフォルトは管理者・キャプテンに**共有**。部員が**非公開**に切替可能 |
| 体調非公開 | **非公開にする場合は理由の入力が必須**（先生・マネージャーのみ閲覧） |
| 体調非公開バッジ | 名簿は通常表示。**管理者向け一覧**にのみ「非公開あり」 |
| 体調代理入力 | **先生・マネージャー**が代理入力可 |
| 練習メニュー作成 | ブロック長=担当 / キャプテン・先生・マネージャー=全部。**テンプレ＋チェックボックス**＋詳細編集 |
| スケジュール | 大会日程カレンダー + **当日「何時・誰・何種目」** の出場表。**全員閲覧** |
| 体調報告 UI | **病院風の部位図**（どこが痛いかタップ） |
| ブロック長任命 | **先生・キャプテンのみ**が名簿で `isBlockLeader` を設定 |
| 種目ブロック | **短距離 / 短長距離 / 跳躍**（+ 共通） |
| 種目マスタ | 下記 [種目マスタ](#種目マスタ確定) の17種目 |
| レベルタグ | **使わない**（学年・種目タグのみ） |
| 同日複数メニュー | **同ブロックで複数件可** |
| 連絡先 | **管理しない**（名簿・個人ページに項目なし） |
| 公開サイト: PB | **種目別ランキングのみ**（イニシャル or 匿名） |
| 公開サイト: 大会日程 | **載せる**（週間練習スケジュールも現行どおり公開） |
| 保護者向け体調 | **なし**（LINE で連絡） |
| LINE 連携 | **なし**（従来どおり手動） |
| PB グラフ体調帯 | **不要**（体調タブで確認） |
| 卒部後データ | **卒部処理時に即削除**（PB・体調・個人データ） |

## UC-A01: ログインする ✅ 決定

| 項目 | 内容 |
|------|------|
| ログイン方式 | **メール+パスワード** と **Google** の両方 |
| 初回登録 | `/login` から部員が自分で登録（UC-R01 参照） |
| ロール判定後の遷移 | 部員 → `/member`、管理者系 → `/admin` |

### 基本フロー（確定版）

1. `/login` を開く
2. 「メールでログイン」または「Googleでログイン」を選択
3. 認証成功
4. `users` コレクションの `role` を参照
5. ロールに応じたホームへ遷移

### 代替フロー

- 名簿未登録・未紐づけ → 「管理者に連絡してください」
- ログインメールと名簿のメールが不一致 → 管理者が名簿画面で手動紐づけ

## UC-R01: 部員を名簿に登録する ✅ 決定

| 項目 | 内容 |
|------|------|
| 名簿登録 | マネージャー / 先生 |
| アカウント作成 | 部員が **`/login` から自己登録**（招待リンクは使わない） |
| 紐づけ | 名簿の**メールアドレス**と一致 → 自動。不一致時は管理者が手動紐づけ |

### 基本フロー（確定版）

1. 管理者が名簿に部員を追加（氏名・学年・種目・**メールアドレス**等）
2. 部員が `/login` からメール or Google でアカウント作成
3. メール一致 → 自動的に `users.memberId` と名簿が紐づく
4. 不一致時 → 管理者が名簿画面で手動紐づけ
5. 部員は `/member` にアクセス可能に

## UC-P01: PB を登録・更新する ✅ 決定

| 項目 | 内容 |
|------|------|
| 入力者 | **部員本人** + キャプテン / マネージャー / 先生 |
| 承認フロー | **なし**（自己入力は即反映） |
| 最新 PB | 登録記録の中で最良の値を自動採用 |
| 削除 | **部員は削除不可**。キャプテン / マネージャー / 先生が削除可 |

### 基本フロー（部員）

1. マイページ → 記録タブ → 「記録を追加」
2. 種目・記録・計測日・公式/練習を入力
3. 保存 → 即グラフ・履歴に反映

### 基本フロー（管理者）

1. 個人ページ or PB 管理から対象部員を選択
2. 同様に入力・保存（部員と同じフォーム）

### 注意

- 部員が誤入力した場合: 本人は**編集のみ**（削除不可）。削除は管理者に依頼
- 練習記録もグラフに載せる（確定）

## UC-H01〜H04: 体調・痛み ✅ 決定

| 項目 | 内容 |
|------|------|
| 入力者 | 部員本人 + **先生・マネージャー**（代理入力可） |
| デフォルトの公開範囲 | 先生・マネージャー・**キャプテン**が閲覧可 |
| 非公開オプション | 部員が報告時に「非公開」を選択可能 |
| **非公開時の理由** | **必須**（空欄では送信不可） |
| 非公開時の閲覧者 | **先生・マネージャーのみ**（キャプテン・他部員は不可）。理由も同範囲 |

### 基本フロー（部員・公開）

1. 体調報告を開く
2. **体のイラストで痛む部位をタップ**（前面/背面、左右）
3. 痛みレベル・きっかけ・今日の練習希望等を入力
4. 公開範囲: デフォルト「共有」
5. 送信 → 体調注意者一覧・個人ステータスバッジに反映

### 基本フロー（部員・非公開）

1. 同上（部位図 → 痛みの詳細）
2. 「非公開にする」にチェック
3. **非公開の理由**を入力（必須。例: 詳細を話したくない、個人的な事情 等）
4. 理由未入力の場合は送信ボタンを無効化しエラー表示
5. 送信 → 先生・マネージャーのみ一覧に表示（理由付き）

### 個人ページ・名簿のステータス表示

| 状態 | 名簿一覧（部員・キャプテン向け） | 管理者向け一覧 |
|------|--------------------------------|----------------|
| 公開の体調報告あり | `○○負傷中` 等のバッジ | 同上 + 詳細リンク |
| 非公開の体調報告のみ | **バッジなし**（通常表示） | **「非公開あり」** バッジ |

## UC-T01: 練習メニュー作成 ✅ 決定

| ロール | 作成・詳細編集 |
|--------|---------------|
| **ブロック長** | 担当ブロックのみ |
| **キャプテン**（1人） | 全ブロック |
| **先生** | 全ブロック |
| **マネージャー** | 全ブロック |
| **部員** | **不可**（閲覧のみ） |

### 作成方式（確定）

1. **テンプレート**をブロック・種目ごとにあらかじめ登録
2. 日次メニューはテンプレ一覧から**チェックボックスで選択**
3. 選んだ内容を **4ロールが詳細編集**（本数・強度・行の追加削除等）

詳細: [4.5 テンプレートとメニュー作成](./04-training-menu.md#45-テンプレートとメニュー作成確定)

### ブロック長の定義・任命

- キャプテンは部内で **1人**
- 種目ごとのリーダーは「ブロック長」として名簿にフラグ（例: `isBlockLeader: true`, `leaderBlock: 短距離`）
- **任命者:** **先生・キャプテンのみ**が名簿画面で設定（マネージャーは不可）
- ブロック長はメニュー作成権限のみ付与（名簿編集は不可）

### 基本フロー（4ロール）

1. 日付・ブロック・タグを選ぶ
2. テンプレート一覧に**チェック** → 内容行が並ぶ
3. 必要なら本数・強度・備考を**詳細編集**
4. 保存

## UC-S01: スケジュール・大会当日 ✅ 決定

| 項目 | 内容 |
|------|------|
| 閲覧 | **全員**（部員含む） |
| 編集 | マネージャー・先生 |
| 大会日程 | カレンダー・一覧で「いつ大会があるか」を表示 |
| **大会当日** | **開始時刻 × 部員 × 種目** のタイムライン（出場表） |
| 部員マイページ | **自分の出場時刻のみ** も表示 |

### 基本フロー（大会当日・部員）

1. スケジュール or マイページを開く
2. 今日の大会 → **自分の種目の開始時刻**を確認
3. 全体タイムラインも閲覧可（誰が何時に出るか）

### 基本フロー（マネージャー）

1. 大会登録 → エントリー入力
2. 大会要項が出たら **当日タイムテーブル**（時刻・組）を入力
3. 部員全員が閲覧

詳細: [5.3〜5.4 スケジュール](./05-schedule.md)

## UC-R04: キャプテンが部員のロールを変更する ✅ 決定

| 項目 | 内容 |
|------|------|
| 操作者 | **キャプテン・先生** |
| 変更可能なロール | `member` ↔ `block_leader`（担当ブロックの設定含む） |
| 変更不可ロール | `teacher`・`manager`・`captain`（管理者ロールは変更不可） |
| `captain` ロールの変更 | **先生のみ**（キャプテン自身は不可） |

### 基本フロー

1. 名簿画面で対象の部員を選択
2. 「ロール変更」をタップ
3. 変更後のロール（`member` / `block_leader`）を選択
4. `block_leader` を選んだ場合は担当ブロック（短距離 / 短長距離 / 跳躍）も設定
5. 保存 → 即時反映（対象部員の次回ログイン時に新ロールが適用）

### 注意

- キャプテン1人制のため、`captain` ロールへの変更は先生のみ
- `teacher`・`manager` ロールはシステム管理者が別途設定（アプリ内では変更不可）
- ブロック長を解除する場合はロールを `member` に戻し、`leaderBlock` をクリア

## 公開サイト・データ保持 ✅ 決定

### 公開サイト（noda-tandf-club.vercel.app）

| 情報 | 公開 | 内容 |
|------|------|------|
| ニュース | ○ | 現行維持 |
| 週間練習スケジュール | ○ | 管理画面から反映 |
| **大会日程** | ○ | 日付・大会名・場所（個人名なし） |
| 部員数集計 | ○ | 学年・男女比のみ |
| **PB ランキング** | ○ | **種目別**。表示名は**イニシャル or 匿名** |
| 練習メニュー詳細 | × | 内部のみ |
| 体調・名簿 | × | 内部のみ |

### 卒部後のデータ

| 項目 | 方針 |
|------|------|
| タイミング | **卒部処理と同時に削除** |
| 対象 | PB 履歴、体調報告、個人メモ、ログインアカウント |
| 公開ランキング | 卒部時に当該部員の掲載行を除去 |
| 名簿 | ステータスを「卒部」にしたうえで個人識別情報を削除 or レコード削除 |

### スコープ外（恒久）

| 項目 | 方針 |
|------|------|
| 保護者向け体調閲覧 | 作らない（LINE） |
| LINE 通知・連携 | 作らない |
| PB グラフの体調帯 | 作らない |
| 休み申請 | 作らない |
| 連絡先管理 | 作らない |
