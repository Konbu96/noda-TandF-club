# 付録: 未確定事項

設計書レビュー時に、顧問先生・キャプテン・マネージャーと決める項目。

| # | 項目 | 選択肢・メモ |
|---|------|-------------|
| 1 | 連絡先（電話番号）を載せるか | 載せる / 載せない / 管理者のみ |
| 2 | PB の自己申告 | 管理者のみ / 部員申告→承認 |
| 3 | キャプテンの編集範囲 | 名簿閲覧のみ？ メニューは担当ブロックのみ？ |
| 4 | 保護者向け体調閲覧 | 将来機能として要否 |
| 5 | PB・大会結果の公開 | 公開サイトに載せるか、部員名の扱い |
| 6 | 休み申請の締切 | 前日何時まで等 |
| 7 | 種目マスタの初期リスト | 部の実際の種目構成 |
| 8 | 種目ブロックの分け方 | ハードルを短距離に含める等 |
| 9 | レベル分けタグ | 新人/記録更新狙い 等を使うか |
| 10 | 同一ブロック複数メニュー | 100m用と200m用を同日に登録する運用 |
| 11 | ステータスバッジ優先順位 | 体調と休みが重なったときの表示 |
| 12 | PB グラフ: 練習記録 | 公式のみ / 練習も載せる |
| 13 | PB グラフ: 体調帯 | 体調不良期間の背景表示を使うか |
| 14 | 名簿一覧のバッジ | 一覧段階で何を見せるか |

## レビューチェックリスト

- [ ] 個人ページで先生が欲しい情報は足りているか
- [ ] 練習メニューのブロック・表示モードは部の練習の分け方と合っているか
- [ ] 体調情報の共有範囲に問題がないか
- [ ] 部員がスマホから入力する項目（休み・体調）は多すぎないか
- [ ] 公開サイトに載せてよい情報の線引きに合意があるか
