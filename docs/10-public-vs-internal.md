# 10. 公開 vs 内部

一般公開サイト（現行 `/`）と内部管理ツールの情報の線引き。

> **確定:** [12. ユースケース決定事項](./12-decided-use-cases.md#公開サイトデータ保持--決定)

---

## 10.1 線引き一覧

| 情報 | 一般公開 | 内部のみ | 備考 |
|------|---------|---------|------|
| ニュース | ○ | | 現行維持（Firestore） |
| 週間練習スケジュール（基本） | ○ | | 管理画面から自動反映 |
| **大会日程** | ○ | | 日付・大会名・場所。個人名なし |
| 部員数（学年・男女比） | ○ | | 集計値のみ |
| **PB ランキング** | ○ | | **種目別**。イニシャル or 匿名のみ |
| PB 推移・個人履歴 | | ○ | |
| 練習メニュー | | ○ | |
| 休み・体調 | | ○ | |
| 名簿 | | ○ | |
| 個人ページ | | ○ | |

## 10.2 公開サイトへの反映フロー

```mermaid
flowchart LR
  AdminSchedule["管理者: スケジュール編集"]
  AdminComp["管理者: 大会日程"]
  AdminPB["管理者: PB 集計"]
  AdminMembers["管理者: 名簿"]
  PublicSchedule["公開: Schedule"]
  PublicComp["公開: 大会日程"]
  PublicRanking["公開: PBランキング"]
  PublicMembers["公開: Members"]

  AdminSchedule --> PublicSchedule
  AdminComp --> PublicComp
  AdminPB -->|"匿名化"| PublicRanking
  AdminMembers -->|"集計のみ"| PublicMembers
```

### 反映対象

| データ | 公開コンポーネント | 内容 |
|--------|------------------|------|
| 週間スケジュール | `Schedule.tsx` | 場所×曜日×説明 |
| 大会日程 | 新規 or News 連携 | 日付・名称・会場 |
| PB ランキング | 新規 | 種目別トップ N。表示名はイニシャル |
| 部員数 | `Members.tsx` | 学年・男女比の円グラフ |
| ニュース | `News.tsx` | 現行維持 |

### 反映しないもの

- 個人を特定できる氏名付き PB
- 体調、休み、練習メニューの詳細
- 名簿・連絡先

---

## 10.3 セキュリティ・データ保持

1. 個人を特定できる情報はログイン後のみ
2. 体調データは部員本人 + 管理者のみ（キャプテンは公開分のみ）
3. 公開 API / Firestore Rules で読み取り範囲を制限
4. **卒部処理時に PB・体調・個人データを即削除**。公開ランキングからも除去

詳細は [技術メモ](./appendix/tech-notes.md) を参照。
