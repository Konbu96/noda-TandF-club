  - 月末の振り返り: Googleフォーム
  - 部内連絡: LINE

## 2. 解決したいこと

- メニューの内容を聞くのに時間がかかる
- 試合の時に個人のPBを把握できていない
- 怪我をしている人たちが何をしたらいいかわかっていない
- 月末フォームやその他の質問フォームに答えているかどうかを把握しづらい
- 徴収するべきお金を集めているかどうかを把握しづらい

## 3. ユースケース

- 部員（キャプテン・ブロック長含む）・顧問がアプリにサインインする
- 部員が個人ページを確認する
- 顧問がブロック内の部
  員の個人ページを見る
- ブロック長がブロック内の部員の個人ページを見る
- 顧問がメニューを登録・編集する
- 顧問が試合前に部員のPBを一覧で確認する
- 部員がアプリでその日のメニューを確認する
- キャプテンが未回答の部員を確認する
- 部員がアプリ内で質問フォームに回答する
- 顧問が大会要項を登録する
- 部員が大会要項を確認する
- システムがフォーム未回答の部員に通知を送る
- キャプテン・担当者がフォーム未回答の部員に通知を送る

## 4. 大まかな機能

- 個人ページ（記録の推移グラフ、PB、ゼッケン番号、定期休養の曜日）
- アプリ内でメニューの情報を確認できる
- ブロックごとの情報が確認できる
- 新入部員向けの基礎情報ページ
- 大会要項をまとめたページ

## 5. ユーザーと権限

- 顧問
- キャプテン
- マネージャー
- ブロック長
- 部員
