# 2. 利用者と役割

## 2.1 利用者モデル

**管理者側**（先生・マネージャー・キャプテン）と**部員**の両方がログインする。

| ロール | 想定ユーザー | 主な役割 |
|--------|-------------|---------|
| `teacher` | 顧問・先生 | 全体監督、名簿管理、体調の最終判断 |
| `manager` | マネージャー | 名簿・スケジュール・大会・メニューの運営 |
| `captain` | キャプテン | 担当種目/学年のメニュー作成、部員フォロー |
| `member` | 部員 | 自分の情報閲覧、休み・体調の入力 |

## 2.2 機能別権限（概要）

△ = 要確認（[未確定事項](./appendix/open-questions.md) 参照）

## 2.3 キャプテンの「担当グループ」

キャプテンが閲覧・編集できる範囲は、名簿の **主種目ブロック** または **学年** で定義する想定（詳細は未確定）。

例: 短距離キャプテン → 短距離ブロックの部員 + 短距離メニューの編集権限
