# 2. 利用者と役割

> **確定事項:** [12. ユースケース決定事項](./12-decided-use-cases.md)

## 2.1 利用者モデル

**ユーザーは部内の全員。** 先生・マネージャー・キャプテン・ブロック長・部員がそれぞれログインして使う。

| ロール | 想定ユーザー | 主な役割 |
|--------|-------------|---------|
| `teacher` | 顧問・先生 | 全体監督、名簿管理、体調の最終判断、全ブロックメニュー |
| `manager` | マネージャー | 名簿・スケジュール・大会・メニューの運営 |
| `captain` | キャプテン（**1人**） | 全部員閲覧、**全ブロック**メニュー作成、体調フォロー |
| `block_leader` | ブロック長（種目リーダー） | **担当ブロックのみ**メニュー作成 |
| `member` | 部員 | 自分の PB・体調入力、メニュー・大会スケジュール閲覧 |

### 部員アカウント

- 管理者が名簿に部員を登録（**メールアドレス**を記載）
- 部員は **`/login` から自己登録**（メール or Google）
- 名簿メールと一致すれば自動紐づけ。不一致時は管理者が手動紐づけ
- ログイン方式は **メール/パスワードと Google の両方** に対応

## 2.3 ブロック長の定義

- **キャプテンは1人**。部全体のリーダー
- **ブロック長**は種目ブロック（短距離・短長距離・跳躍）ごとのリーダー
- 名簿上で `isBlockLeader` + `leaderBlock` を設定（**先生・キャプテン**が任命）
- 権限は**練習メニュー作成（担当ブロックのみ）** が中心。名簿・体調の管理権限は持たない
- **ブロック長の任命**は先生・キャプテンのみ。マネージャーは任命できない

## 2.4 キャプテンの閲覧・編集範囲

| 種類 | 範囲 |
|------|------|
| 閲覧 | **全部員**の個人ページ |
| 編集 | PB・メニューは全員分可。名簿本体は G/T のみ |
| 体調 | 公開設定の報告のみ閲覧可 |
