# 5. スケジュール管理

現行公開サイトの週間スケジュール（学校=月火木金、競技場=水土、日=休み）はコードに固定されている。これを**編集可能**にし、**単発の変更**も扱う。

---

## 5.1 週間基本スケジュール

学期ごとに有効な「基本の型」。

| 項目 | 内容 | 現行サイト |
|------|------|-----------|
| 場所 | 学校 / 競技場 / 休み | 現行3行 |
| 曜日 | 月〜日 | 同左 |
| 内容説明 | 走り系、専門競技 等 | description |
| 有効期間 | 例: 2026年度 第1学期 | 新規 |
| 公開するか | 一般サイトに載せる / 内部のみ | 新規 |

**運用:** 学期初めにマネージャーが登録 → 公開サイトに自動反映

---

## 5.2 単発イベント・変更

基本スケジュールを上書きする「例外」。

| 種別 | 例 | 管理項目 |
|------|-----|---------|
| 大会 | 県大会 | 日付、会場、終日/午後、対象 |
| 記録会 | 校内記録会 | 同上 |
| 合宿 | 夏合宿 | 期間、場所、持ち物 |
| 休練 | 試験期間 | 日付、理由 |
| 練習変更 | 雨で体育館 | 変更後の場所・内容 |
| 学校行事 | 文化祭準備 | 練習調整 |

### 運用シーン

- 天候変更: 当日朝に「競技場 → 学校」に変更
- 大会前後: 練習時間短縮を明記

---

## 5.3 カレンダー表示

| 表示 | 内容 |
|------|------|
| 月表示 | 練習日 / 大会 / 休み を色分け |
| 週表示 | 今週の予定一覧 |
| 今日 | 場所・時間・特記事項 |
