# 5. スケジュール管理

現行公開サイトの週間スケジュール（学校=月火木金、競技場=水土、日=休み）はコードに固定されている。これを**編集可能**にし、**大会日程**と**大会当日の出場時刻**も把握できるようにする。

> **全員**が大会日程・当日タイムテーブルを閲覧できる。編集はマネージャー・先生。

---

## 5.1 週間基本スケジュール

学期ごとに有効な「基本の型」。

| 項目 | 内容 | 現行サイト |
|------|------|-----------|
| 場所 | 学校 / 競技場 / 休み | 現行3行 |
| 曜日 | 月〜日 | 同左 |
| 内容説明 | 走り系、専門競技 等 | description |
| 有効期間 | 例: 2026年度 第1学期 | 新規 |
| 公開するか | 一般サイトに載せる / 内部のみ | 新規 |

**運用:** 学期初めにマネージャーが登録 → 公開サイトに自動反映

---

## 5.2 単発イベント・変更

基本スケジュールを上書きする「例外」。

| 種別 | 例 | 管理項目 |
|------|-----|---------|
| 大会 | 県大会 | 日付、会場、終日/午後、対象 |
| 記録会 | 校内記録会 | 同上 |
| 合宿 | 夏合宿 | 期間、場所、持ち物 |
| 休練 | 試験期間 | 日付、理由 |
| 練習変更 | 雨で体育館 | 変更後の場所・内容 |
| 学校行事 | 文化祭準備 | 練習調整 |

### 運用シーン

- 天候変更: 当日朝に「競技場 → 学校」に変更
- 大会前後: 練習時間短縮を明記

---

## 5.3 大会日程（カレンダー）

**いつ大会があるか**を部員全員が把握できる。

| 表示 | 内容 |
|------|------|
| 月カレンダー | 大会日を強調表示（練習日 / 大会 / 休み を色分け） |
| 大会一覧 | 今後 N 件の大会（名称・日付・会場・エントリー締切） |
| 大会詳細 | 大会マスタ + エントリー部員一覧へのリンク |

公開サイトには **大会日程（日付・名称・会場）** を反映（個人名なし）。

---

## 5.4 大会当日スケジュール（出場表）

**大会当日、「何時に誰の種目があるか」** をタイムラインで見られる。

### 管理する情報（1行 = 1出場）

| 項目 | 内容 | 例 |
|------|------|-----|
| 大会 | どの大会か | 県大会 |
| 日付 | 大会当日 | 2026-05-10 |
| **開始時刻** | 競技開始予定 | 10:35 |
| **種目** | 種目マスタから | 100m 男子 |
| **部員** | 名簿から | 田中 A |
| 組・レーン | 任意 | 2組 3レーン |
| 備考 | 集合時刻、ウォームアップ場所 等 | 9:30 競技場集合 |

### 画面イメージ

**大会当日ビュー**（部員・管理者共通）

```
県大会 — 2026/5/10

09:30  全体集合（競技場正門）
10:15  ウォームアップ開始
10:35  田中 A — 100m 男子（2組）
11:20  佐藤 B — 400m 男子（1組）
14:00  リレー 4×100m 男子 — 田中 A, 鈴木 C, …
```

| 表示モード | 用途 |
|-----------|------|
| **時刻順（全体）** | マネージャー・先生が当日の流れを把握 |
| **自分の出場のみ** | 部員マイページ。「次の種目まであと30分」等 |
| **種目別** | 100m 担当者がまとめて見る |

### 入力フロー

1. マネージャーが大会を登録（[3.3 大会管理](./03-member-management.md#33-大会記録会の管理)）
2. エントリー（誰が何種目に出るか）を入力
3. **大会当日タイムテーブル**に時刻・組を追記（大会要項が出たら更新）
4. 部員全員がスケジュール画面 or マイページで確認
