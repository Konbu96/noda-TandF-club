# 野田学園陸上競技部 内部管理ツール 設計書

> **ステータス:** 要件確定（ユースケース決定済み）  
> **対象:** 一般公開サイトとは別に追加する、管理者・部員向けログイン機能

## この設計書について

部活動の運営で実際に困っていることと、システムに載せる情報・機能を定義するドキュメントです。実装の手順より、**何を管理するか・誰が何をするか**を主役にしています。

## 用語集

| 用語 | 説明 |
|------|------|
| PB | Personal Best（自己ベスト）。種目ごとの最高記録 |
| 種目ブロック | 短距離・短長距離・跳躍・共通の練習グループ |
| 個人ページ | 1人の部員に関する情報を横断表示する統合ビュー |
| RPE | Rate of Perceived Exertion。主観的運動強度（1〜10） |

## 現行サイトとの関係

- **一般公開:** 現行の [`/`](../src/app/page.tsx) ランディング・[`/news`](../src/app/news/page.tsx) は維持
- **内部ツール:** `/login`, `/member/*`, `/admin/*` として新規追加（予定）
- **技術:** Next.js 15 + Firebase Firestore（現行と同じ）
