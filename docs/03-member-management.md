# 3. 部員情報管理

部活動の中心となる「誰がどんな選手か」を一元管理する。個人情報を含むため、**ログイン後のみ**アクセス可能。

名簿から部員を選択すると [個人ページ（統合ビュー）](./07-member-profile.md) へ遷移する。

---

## 3.1 基本プロフィール（名簿）

### 管理する情報

| 項目 | 内容 | 備考 |
|------|------|------|
| 氏名 | フルネーム | 公開サイトには載せない |
| ふりがな | ソート・検索用 | |
| **メールアドレス** | ログインアカウント紐づけ用 | 自己登録時に一致で自動紐づけ |
| 学年 | 中1〜高3 | 公開サイトの部員数集計に利用可 |
| 性別 | 男子 / 女子 | 同上 |
| 所属 | 中学部 / 高校部 | |
| 主種目 | 短距離、短長距離、跳躍 等 | 種目マスタから複数選択可 |
| 副種目 | 同上 | 任意 |
| 役職 | キャプテン、ブロック長、マネージャー 等 | 任意 |
| 入部年月 | | 在籍期間の把握 |
| 卒部予定 | 高3の卒業年度 等 | 任意 |
| ステータス | 在籍 / 休部 / 卒部 | 卒部時に個人データ削除 |
| メモ | アレルギー、配慮事項 等 | 管理者のみ |

**連絡先（電話番号・保護者連絡先等）は管理しない。**

### 誰が何をするか

- **先生・マネージャー:** 名簿の追加・編集・卒部処理（卒部時に PB・体調等を削除）
- **キャプテン:** 全部員の閲覧（名簿編集は G/T のみ）
- **部員:** 自分の基本情報の閲覧

### 画面

- 部員一覧（学年・種目・名前でフィルタ、ステータスバッジ付き）
- 行クリック → [個人ページ](./07-member-profile.md)

## 3.2 自己ベスト（PB）管理

種目ごとに**最新 PB** と**更新履歴**の両方を保持する。

### 管理する情報

| 項目 | 内容 | 備考 |
|------|------|------|
| 種目 | 100m、200m、400m、800m、1500m、走幅跳 等 | 種目マスタで統一 |
| 記録 | タイム（秒）または 距離/高さ（m） | 種目に応じた入力形式 |
| 計測日 | | |
| 計測場所 | 練習 / 大会名 | |
| 風速 | m/s | 短距離・跳躍等 |
| 公式記録か | 是 / 否 | 練習タイムと区別 |
| 備考 | スタート、コンディション 等 | 任意 |
| 更新者 | 誰が登録したか | 監査用 |

### 運用シーン

- **練習後:** マネージャー or キャプテンが記録を入力
- **大会後:** 結果を PB として登録（既存 PB より良い場合は最新 PB を更新）
- **部員:** 自分の PB を [個人ページ](./07-member-profile.md) で確認

### 一覧・分析

- 種目別 PB ランキング（部内）
- 個人ページ: 種目ごとの [PB 推移グラフ](./07-member-profile.md#タブ1-記録推移個人-pb-推移グラフ)
- 大会エントリー時の現在記録参照

## 3.3 大会・記録会の管理

**大会マスタ**（大会そのもの）と**エントリー・結果**（誰が出るか）を分けて管理する。

### 大会マスタ

| 項目 | 内容 |
|------|------|
| 大会名 | 例: 県大会、記録会、新人戦 |
| 開催日 | 単日 or 期間 |
| 会場 | |
| 種別 | 公式大会 / 記録会 / 交流試合 |
| 締切日 | エントリー締切 |
| 備考 | 集合時間、ユニフォーム 等 |

### エントリー（部員 × 大会）

| 項目 | 内容 |
|------|------|
| 出場種目 | 複数可 |
| エントリー記録 | 申請時点の PB |
| ステータス | 予定 / 出場 / 棄権 / 完了 |
| 結果 | 順位、記録、風速 |
| 備考 | 棄権理由 等 |

### 大会当日タイムテーブル

[5.4 大会当日スケジュール](./05-schedule.md#54-大会当日スケジュール出場表) と連動。エントリー確定後、**開始時刻・組・レーン**を追記する。

| 項目 | 内容 |
|------|------|
| 開始時刻 | 例: 10:35 |
| 種目 | エントリーと紐づけ |
| 部員 | エントリーと紐づけ |
| 組・レーン | 大会要項に基づく |
| 集合時刻 | 任意 |

**全員**が当日ビューで「何時に誰の種目か」を確認できる。

### 運用シーン

- 大会2週間前: マネージャーが大会を登録、エントリーを整理
- 大会前日: 当日タイムテーブルを入力・更新
- 大会当日: 部員がマイページで自分の出場時刻を確認。マネージャーが全体の流れを把握
- 大会後: 結果が PB を更新、体調報告と紐づけ（痛めた場合）

## 3.4 休み・欠席管理

「今日・今週誰が来ないか」を共有する。体調管理と連携するが、**学校行事など体調以外の休み**も扱う。

### 管理する情報

| 項目 | 内容 |
|------|------|
| 日付 | 単日 or 期間 |
| 種別 | 練習欠 / 学校行事 / 家庭都合 / 体調不良 / その他 |
| 理由（詳細） | 自由記述（任意） |
| 申請日 | |
| ステータス | 申請中 / 承認 / 却下 |
| 承認者 | 先生 or マネージャー |
| 練習への影響 | 全休 / 見学のみ / 軽め参加可 |

### 運用シーン

- **部員:** 前日までに休みを申請
- **マネージャー:** 翌日の練習前に欠席者一覧を確認
- **キャプテン:** 種目練習の人数調整

### ダッシュボード

- 今日の欠席者リスト
- 今週の欠席予定カレンダー
- 個人ページ: 今月/今学期の休み日数、種別内訳
